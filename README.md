# ld-shell.github.io

This repository serves the root of `ld-shell.github.io`. It holds only
`robots.txt`, which search engines read at the root of the host and nowhere
else, and which lists the sitemap of each project site, such as
[beamfeat's documentation](https://ld-shell.github.io/beamfeat/).

When a project gets a documentation site of its own, add its sitemap to
`robots.txt`.

`googleebd0e6c5a45bfff4.html` verifies the site for Google Search Console,
where the sitemaps are submitted; it has to stay in place for the
verification to hold. `.nojekyll` keeps GitHub Pages from turning this README into a
home page.
